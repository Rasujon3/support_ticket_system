# 🛠️ Support Ticket System

A lightweight, modular support ticket system built with Laravel 9 using the **Repository Pattern**, **Bootstrap 5**, and **AdminLTE**. The system allows users to submit support tickets and administrators to manage, assign, and update their statuses.

---

## 📁 Features

- Modular Laravel 9 architecture
- Repository Pattern for clean, testable code
- User authentication (registration, login)
- Ticket creation with messaging and file attachment support
- Admin dashboard (AdminLTE) for ticket management
- Role-based access (user vs admin)
- Only assigned admin can update ticket status
- File upload & download
- Secure input validation and output escaping

---

## 🧱 Technologies Used

- Laravel 9
- MySQL
- Bootstrap 5
- AdminLTE
- JavaScript & AJAX
- Laravel Modules
